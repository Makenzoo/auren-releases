# AUREN releases

This public repository hosts downloadable AUREN application builds and the launcher catalog (`latest.json`). Application installers are published as GitHub Release assets. The catalog is updated by the release workflow after a tagged Windows build.

Do not upload application source code, AUREN Admin, signing private keys, customer license files, or credentials here. The `latest.json` catalog will remain empty until the source repository is connected to the release workflow and the first signed-app build is published.

Customers download the AUREN Launcher and use it to install POS, Back Office, and Server. A valid license issued by AUREN Admin is required when each application starts.
